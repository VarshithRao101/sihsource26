Model & assumptions

  • Storage curve V = V_max (y/H)k, k = 2.7 for a steep valley. Set k = 1 for a prismatic tank, where y = V/A holds exactly. USACE HEC-RAS reservoir storage approximation.
  • Outlet is an orifice, Q = Cd A √(2g·h), Cd = 0.6. Fread (1988), BREACH, §3.
  • Spillway is a broad-crested weir, Q = 1.7·L·h1.5. USACE HEC-RAS.
  • Inflow is a steady base flow plus an optional synthetic Gaussian flood wave. It is not a measured hydrograph.
  • Euler integration at fixed dt, substepped so no step moves more than 1 % of capacity. Speed changes the number of steps per second, never dt.
